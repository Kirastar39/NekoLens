# NekoLens —— 实时交互场景的轻量级端到端视觉翻译系统

[![Python](https://img.shields.io/badge/Python-3.9%2B-blue.svg)](https://www.python.org/)
[![Platform](https://img.shields.io/badge/Platform-Windows%2010%2F11-0078d7.svg)]()
[![License](https://img.shields.io/badge/License-MIT-green.svg)]()

基于 Windows 10/11 原生离线 WinRT OCR 与大模型流式接口（OpenAI 兼容）构建的**轻量级桌面级屏幕实时翻译系统**。

针对桌面多语种阅读与游戏本地化（视觉小说/ADV）场景，摒弃高延迟、高成本的纯多模态大模型（VLM）直推方案，采用 **“端侧原生轻量 OCR 定位 + 云端纯文本 LLM 极速重构”** 的两阶段流水线。将端到端首字上屏时间（TTFT）压缩至 **600ms 内**，Token 成本降低 **80%+**。

**[点击此处前往 Releases 下载免安装单文件版 (NekoLens.exe)](https://github.com/Kirastar39/NekoLens/releases/latest)**

## 核心功能与交互模式

- **三种翻译视图模式**
  - **覆盖模式（In-place Overlay）**：原位擦除原文并贴合绘制译文。支持流式逐块上屏、AABB 框内自适应字号、鼠标悬停查看原文、以及网页滚轮平滑跟随。
  - **气泡模式（Subtitle Bubble）**：专为 ADV/视觉小说设计的半透明描边字幕窗。支持绑定固定台词区、锁定后隐藏顶栏并开启鼠标点击穿透、台词变化自动触发翻译、附带前文统一角色译名以及历史对白回看。
  - **对照模式（Bilingual View）**：双语穿插流式阅读窗，支持自由拖拽缩放、鼠标选词与一键复制全文。
- **全语种与多厂商生态兼容**：自动扫描本机 Windows OCR 语言包（英、日、韩、俄等）；无缝对接智谱 GLM、DeepSeek、Kimi、OpenAI、Gemini 及本地 Ollama/vLLM 等接口。
- **极致轻量与零待机损耗**：高内聚单文件架构，托盘待机 **0% CPU 占用**；内置温热 OCR 守护管道（闲置 2 分钟自动回收内存）与 1500 容量本地 LRU 语义缓存（高频静态 UI 0ms 瞬时响应）。

## 系统架构与核心工程亮点

### 1. 端到端数据流架构 (Pipeline Architecture)

~~~text
[1. 屏幕捕获层]  DWM 硬件级剔除自身悬浮窗 (SetWindowDisplayAffinity 防自截屏死循环)
       │
       ▼
[2. 图像预处理]  图像灰度横向投影分析 + 3x Lanczos 超采样弱墨迹修复
       │
       ▼
[3. 语义缓存池]  本地 1500 容量 LRU 缓存校验
       │
       ├──► (命中 Cache Hit)  ──► [0ms 瞬时直出] 跳过后续推理，直接交由第 7 层渲染
       │
       └──► (未命中 Cache Miss)
                 │
                 ▼
          [4. 端侧离线定位]  常驻 IPC 守护管道 (stdin/stdout) 调用原生 WinRT OCR 提取坐标词块
                 │
                 ▼
          [5. 上下文构建层]  组装 30 条动态历史滑窗 + 注入角色人称与结构化编号强约束协议
                 │
                 ▼
          [6. 云端流式推理]  手写 SSE 字节流解析器 (防粘包/截断) + 参数自适应降级 + 质量探针重试
                 │
                 ▼
          [7. 视图渲染层]    行截断防抖递增上屏 + AABB 碰撞规避自适应字号排版
~~~

### 2. 核心技术突破

* **两阶段极速流水线与常驻 IPC 管道（性能维度）**
  * 针对 PowerShell 调用 WinRT OCR 冷启动慢（>1.5s）的痛点，构建基于标准输入输出（`stdin/stdout`）的**双向常驻 IPC 管道守护进程**与自动超时回收机制（闲置 120s 释放）。
  * 端到端首字上屏时间（TTFT）压缩至 **600ms 内**（延迟降低 60% 以上），相比纯 VLM 方案节省 **80%+ Token 成本**。
* **上下文感知 Prompt 工程与自动化质量探针（大模型维度）**
  * **动态对话滑窗**：维持前序 30 条对白历史并在 Prompt 中建立强约束协议，解决了视觉小说中角色人称混淆、拟声词丢失与专有名词前后不一致问题。
  * **首轮翻译质量探针（`needs_retranslation`）**：自动正则探测译文中的残留假名、漏翻、编号错位等异常，触发靶向局部微提示词二次重试，杜绝大模型幻觉漏行。
* **高容错自愈协议层与行截断防抖（网络与流式维度）**
  * **手写字节流 SSE 解析器**：有效处理底层 TCP 粘包、半包拆分、非标换行及 UTF-8 多字节字符截断问题。
  * **参数自适应降级状态机**：针对不同大模型厂商 API 差异，自动捕获报错并动态剔除被拒参数（如 `thinking`、`temperature` 越界等），实现跨平台零配置自愈。
  * **行截断防抖算法（Line-Truncation Debounce）**：仅在检测到完整语义行边界时递增渲染，消除了流式吐字时的文字乱跳与排版闪烁。
* **DWM 级无感交互与形态学抗碰撞排版（桌面与视觉维度）**
  * **防递归自截屏死循环**：调用 `WH_MOUSE_LL` 全局底层钩子解耦主线程消息循环；利用 Windows 原生 `SetWindowDisplayAffinity(0x11)` 机制将翻译悬浮窗从系统合成层（DWM）截图中硬件级剔除，完美实现气泡自动监测模式下的“只截游戏不截字幕”。
  * **弱墨迹修复与 AABB 排版引擎**：基于图像灰度横向投影实现 `3x Lanczos` 超采样修复，找回 OCR 易丢失的标点与弱墨迹符号；自研 AABB 碰撞规避排版引擎，动态借用空闲边距并二分适配字号，解决译文长度膨胀导致的 UI 崩坏。

## 环境配置与快速开始

### 1. 安装依赖（Python 3.9+）
```bash
pip install -r requirements.txt
```

### 2. 安装 Windows 原生 OCR 语言包
*以管理员身份运行 PowerShell（体积仅 ~2MB，系统底层组件，不增加多余输入法）：*
```powershell
# 安装英语识别包
Add-WindowsCapability -Online -Name "Language.OCR```en-US~0.0.1.0"

# 安装日语识别包
Add-WindowsCapability -Online -Name "Language.OCR```ja-JP~0.0.1.0"
```

### 3. 启动程序
```bash
python main.py
```
> **首次配置**：启动后右键右下角系统托盘图标 -> **接口配置**，填入兼容 OpenAI 格式的 `API URL`、`模型名称` 与 `API Key` 即可开始使用。

## 快捷键指南

| 快捷键 | 功能 | 详细说明 |
| :--- | :--- | :--- |
| **`Alt + F`** | 框选固定区域 | 可随时重新录制；绑定游戏对话框后配合**气泡自动模式**实现全自动沉浸式翻译 |
| **`Alt + W`** | 窗口翻译 | 左键点选目标窗口进行全窗翻译，右键或 `Esc` 取消 |
| **`Alt + Q`** | 区域翻译 | 左键拖拽框选任意屏幕区域翻译，右键或 `Esc` 取消 |
| **`Alt + R`** | 刷新翻译 | 强制重新 OCR 并翻译上一次锁定的区域 |
| **`Alt + X` / `Esc`** | 清除屏幕 | 覆盖与对照模式下按 `Esc` 即可关闭；**气泡模式下按 `Esc` 不关闭**以防干扰游戏内菜单操作 |
| **`Ctrl + C`** | 复制译文 | 复制当前鼠标选中的文本或窗口内全部译文 |
